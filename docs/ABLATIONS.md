# Ablation studies

Run reported ablations with `pipeline_ablation.py`, `--batchsize 512`, and
`--no-crop`. Configurations are in `configs/pipeline/ablations/`, and the
evaluation settings are in [`configs/ablations.json`](../configs/ablations.json).
Run commands from the repository root and use a new output directory each time.

## Component and model comparisons

Component, segmentation, and geometry-predictor variants use the same
deterministic 100-query subset per UAV split (seed 42). For example:

```bash
PYTHONPATH=. python pipeline_ablation.py \
  --dataset uavd4l --data_root data/UAVD4L-LoD/inTraj \
  --batchsize 512 --no-crop --n 100 --random_seed 42 \
  --config configs/pipeline/ablations/normals_only.yaml \
  --out outputs/ablation_normals_intraj
```

The geometry-predictor comparisons include MoGe-2 ViT-S, ViT-B, and ViT-L,
and Metric3D v2. These model swaps change both depth and normals, not normals
alone. Segmentation can be switched to the off-the-shelf EoMT model
with `configs/pipeline/ablations/seg_eomt.yaml`.

## Map and pose selection

LoD1/LoD3 map comparisons and pose-selection comparisons use the complete
evaluation splits. To select a different UAV map, pass its mesh explicitly:

```bash
PYTHONPATH=. python pipeline.py \
  --dataset uavd4l --data_root data/UAVD4L-LoD/inTraj \
  --mesh_path data/MODEL/ply/UAVD4L-LoD1.ply \
  --batchsize 512 --no-crop \
  --out outputs/eval_uavd4l_intraj_lod1
```

Building-removal studies use the same 100-query subset per split and compare
intact maps with removal of small, middle, or large visible mesh components.

## Prior noise

Prior-noise studies use 300 queries per UAV split (seed 42). Synthetic priors
are generated by perturbing the ground-truth pose in translation and rotation.
The native GPS/IMU-prior comparison uses the same query subset. For example:

```bash
PYTHONPATH=. python pipeline_ablation.py \
  --dataset uavd4l --data_root data/UAVD4L-LoD/inTraj \
  --batchsize 512 --no-crop --n 300 --random_seed 42 \
  --perturb_gt_t 10 --perturb_gt_r 10 --all_6D \
  --out outputs/ablation_prior_10_intraj
```

The coarse search varies translation and yaw. Roll and pitch remain at the
prior until full-pose PnP refinement. Search widths expand with the requested
perturbation magnitude.

The ablation output records the configuration, query set, predictions, and
metrics. Each scenario has its own output directory. Ordinary component and
prior-noise runs use `Baseline/`, while building-removal runs additionally use
`Missing_Small/`, `Missing_Mid/`, and `Missing_Large/`. Summarize a scenario with:

```bash
PYTHONPATH=. python scripts/summarize_results.py outputs/ablation_normals_intraj/Baseline
```
